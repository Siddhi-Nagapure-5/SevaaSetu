# SevaaSetu

A Donation Matching Portal connecting Donors with Receivers.

## Overview

SevaaSetu is a platform designed to bridge the gap between those who wish to donate and those in need. It facilitates a transparent and efficient donation process.

### Roles

*   **Donors:** Users who can list items or funds for donation.
*   **Receivers:** Users or organizations that can request and receive donations.
*   **Admin:** Platform administrators who manage users, oversee transactions, and ensure smooth operation of the portal.

## Project Structure

This project is structured as a full-stack application:

*   `frontend/`: Contains the user interface and client-side logic.
*   `backend/`: Contains the server-side logic, API endpoints, and database interactions.
